# AI-Powered RAG Agent with n8n, Gemini, and Pinecone

This project is an n8n workflow that implements a **Retrieval-Augmented Generation (RAG)** pipeline. It automates the ingestion of documents from Google Drive into a Vector Database (Pinecone) and allows users to chat with that data using Google Gemini.
